# 트리
- 노드들이 나무가지처럼 간선으로 연결된 비선형 계측적 자료구조
- 부모 노드를 기준으로 아래로 가지처럼 뻗어나가는 형식의 구조이다.
- 컴퓨터의 디렉토리 구조가 트리 구조의 대표적인 예시시
- ***트리에서 주로 사용하는 용어***
    - 루트 노드(root) : 가장 시작점의 노드 (레벨 0 )
    - 부모 노드(Parent Node) : 자식 노드가 존재하는 노드
    - 자식 노드(Child Node) : 부모 노드가 존재하는 노드
    - 형제 노드(Sibling Node) : 깊이가 같은 노드
    - 리프 노드(leaf Node) : 자식 노드가 없는 노드
    - 깊이(depth) : 루트 노드 아래로 부모 노드의 갯수
    - 너비(height) : 리프 노드까지의 거리

## 트리의 특징
- 하나의 루트 노드와 다른 하위트리로 구성
- 데이터를 순차적으로 저장하지 않는 ***비선형 자료구조***
- ***n개의 노드와 n-1개의 간선***으로 이뤄짐
- ***단순 순환이 없고, 무방향 그래프 구조***
- 계층형 자료구조

## 트리의 종류
- 편향 트리
    - 모든 노드들이 자식을 하나만 가짐
- 이진트리
    - 각 노도의 자식 노드가 2개 이하인 트리
- m원 탐색 트리
    - 최대 m개 이상의 자식노드를 가지는 트리
- 균형 트리
    - m원 탐색에서 높이 균형을 유지하는 트리
